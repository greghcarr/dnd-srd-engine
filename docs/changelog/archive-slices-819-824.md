**Feat (slice 821): NPC reaction discovery — monster Protective Magic in the affordance layer**
Closes the `npc-reaction-discovery` follow-up (slice 820). Slice 819 wired the Mage/Archmage *Protective Magic* (Counterspell/Shield) cast + metering, but `engine.query.availableReactions` / `reactionsForTrigger` (slices 763-767) enumerate reactions from class features / prepared spells — the Shield + Counterspell registry descriptors' `owns` checked `preparedSpells` and `correlate` required an arcane class + a 3rd-level slot, which a monster lacks — so a consumer couldn't *discover* the Mage's reactions. Extended both descriptors with a monster path: `owns` now also accepts a granted per-day pool with budget (`perDayFreeCastAvailable`, factored out of `resolvePerDayFreeCast` through a shared `resolvePerDayBudget`, gated on `statblockId` to skip the player path's effect-stack build); `correlate` branches to a `useFreeCast` intent (meters via the pool, slice 819) with `castingClassId: ''` (flat statblock DC via the `SetSpellcastingProfile`), reusing the class-independent "+5 flips the hit" / "leveled spell" structural filters. Players unaffected; the 22 existing reaction tests stay green. New 5-test slice-821 (discovery surfaces granted Counterspell/Shield; correlated `useFreeCast` intents are planner-accepted — dispatch emits `PerDayCastUsed`, no caster slot; an exhausted pool hides both; a plain fighter is offered neither). `tsc` clean; coverage/exports snapshots unchanged; fast suite green (603 files, 4607 passed). With this the `npc-caster-*` family is fully closed.

**Feat (slice 820): Dryad Tree Stride — the last bonus-action-group item (and the only non-spell one)**
Fully closes the [L7 audit](l7-completion-audit.md) `npc-caster-bonus-action-groups` quirk (slices 815-820). The Dryad's RAW Bonus Action *Tree Stride* teleports tree-to-tree (≤ 60 ft); the trees are terrain the engine doesn't model (positions are tracked, terrain is consumer-managed), so the tree-adjacency is a consumer seam — the engine owns the turn/economy/range/occupancy. Mirrors `planCloudsJaunt`: a new zero-arg `GrantTreeStride` marker effect (parallel to `GrantMagicResistance` — union + zod + `EFFECT_KINDS` + a `hasTreeStride()` builder flag, gating the ability data-drivenly vs hardcoding the statblock id) + a new `planTreeStride` planner (checks the marker, active turn, Bonus Action, ≤ 60 ft Chebyshev, unoccupied; emits `ActionEconomyConsumed(bonusAction)` + `CombatantMoved` with `feetTraveled: 0`; no resource — at-will given trees). Wired as `engine.plan.treeStride`, allowlisted in the planner-wiring audit. Content: the Dryad gains the marker. The new `EFFECT_KINDS` entry bumped the effect-kind count (68→69 / 67→68), so six front-door doc citations were updated. New 6-test slice-820 (teleport without movement drain; range/occupancy/bonus-action/not-a-Tree-Strider rejections). Follow-up tracked: `npc-reaction-discovery` (surfacing monster reaction groups in `availableReactions`). `tsc` clean; coverage/exports snapshots unchanged; fast suite green (602 files, 4602 passed).

**Feat (slice 819): Protective Magic (3/Day) — monster Counterspell/Shield as a per-day-pooled reaction**
Advances the [L7 audit](l7-completion-audit.md) `npc-caster-bonus-action-groups` quirk — its last spell item. The Mage/Archmage Reaction *Protective Magic (3/Day)* casts Counterspell or Shield, but both are dedicated slot-consuming planners (off the generic `castSpell` path, like Misty Step) sharing one 3/Day budget. With three such dedicated planners now needing slot-less NPC metering, the duplicated logic was extracted into a shared **`resolvePerDayFreeCast`** helper (resolves the `perLongRest` grant, checks the budget — pooled via slice-818 `perDayPoolId`, else per-spell — and returns the `PerDayCastUsed` to emit instead of `SpellSlotConsumed`); **Misty Step (817) was refactored onto it**, and `planCounterspell`/`planShield` use it under a new `useFreeCast` intent flag (the caster's slot becomes a per-day pool draw; the countered caster's slot loss + the CON save / +5 AC are untouched). Content: Mage + Archmage grant Counterspell + Shield (`perDayPoolId: 'protective-magic'`, 3/Day, INT). The cast+metering seam ships here; surfacing it in the reaction-discovery affordance layer is a separate query-layer concern. New 5-test slice-819 (each cast as a Reaction = reaction economy + PerDayCastUsed no caster slot; the shared-budget proof — three Counterspells block a never-cast Shield; long-rest refresh); player slot Shield/Counterspell + Misty Step stay green. `tsc` clean; coverage/exports snapshots unchanged; fast suite green (601 files, 4596 passed).
