**Feat (slice 829): Air Elemental Whirlwind — save-action Recharge + forced push**

New **`SaveActionSpec.recharge` (`{ rechargeMin }`)** — the same Recharge economy as `breathWeapon`: `planSaveAction` marks a recharge-gated action expended on use (re-fire throws while expended), and the new `planSaveActionRechargeAtTurnStart` rolls a d6 at turn-start (wired into the three turn-start sites) and clears it on a roll ≥ `rechargeMin`; state on the new per-id `Character.expendedSaveActionIds`. New **`onFail.pushFeet`** emits a position-less `CreaturePushed` on a failed save (consumer applies the displacement). New `SaveActionExpended` / `SaveActionRecharged` lifecycle events (+ reducers / apply cases / transcript formatters), mirroring the breath-weapon pair. Content: the Air Elemental Whirlwind (Recharge 4–6, STR DC 13, ≤Medium, 4d10+2 thunder + 20-ft push + Prone, `halfDamageOnSuccess`). No new condition/effect kind (reuses prone/thunder) → no doc-counts bump; the migrations test confirms the new field's back-compat. New 5-test slice-829 (spec + fail payload + half-on-success + expended gate + end-to-end turn-start recharge). `tsc` clean; fast suite green (610 files, 4645 passed).

**Feat (slice 828): monster save-action mechanism (Constrict) — closes `monster-onhit-rider-pass`**
The last open shape of the [L7 audit](l7-completion-audit.md) `monster-onhit-rider-pass` quirk: the **save-action** (an auto-hit, *no-attack-roll* action resolved by a saving throw, where a failed save deals damage + applies condition(s)). The on-hit-rider machinery couldn't express it (no hit to hang on). New statblock **`saveActions: []`** field (`SaveActionSpec`: save ability/DC, reach, `maxTargetSize` gate, `onFail.damage[]` + `onFail.applyConditionIds[]`, `halfDamageOnSuccess`) + **`engine.plan.saveAction`** — the save-or-effect sibling of `breathWeapon` (single-target, no recharge, condition-primary; nothing on a success). On a fail it runs the standard mitigation/fatal-intercept/concentration pipeline (damage sourced to the monster) and stamps the monster as each condition's source (Grappled grappler resolves) + autoExpiry. Action economy is consumer-owned (Constrict bundles into Multiattack for some, standalone for others; the multiattack schema can't say "uses Constrict"). Shipped on the in-scope **Constrict** family, each SRD-verified: **Behir** (STR DC 18, ≤Large, 5d8+6, Grappled+Restrained), **Couatl** (DC 15, ≤Medium, 1d6+5, +Restrained), **Salamander** (DC 15, ≤Large, 2d6+4 + 2d6 fire, +Restrained), **Constrictor Snake** (DC 12, ≤Medium, 3d4, Grappled only). Audit corrections: **Marilith is CR 16** (out of scope) and there is no Giant Constrictor in the pack. The two whirlwind shapes (Air Elemental recharge+push+half; Djinni Concentration cylinder) are genuinely different — split out as `monster-whirlwind-actions`. New pack-integrity guard (save-action conditions resolve) + 6-test slice-828. `tsc` clean; no new effect kind/condition (reuses grappled/restrained) so no doc-counts bump; fast suite green (609 files, 4640 passed).
Detail: [slice-828.md](slice-828.md).

**Feat (slice 825): Bearded Devil infernal wound — recurring-damage condition mechanism**
Advances the [L7 audit](l7-completion-audit.md) `monster-onhit-rider-pass` quirk (batch 3) with the hardest rider remainder. The engine had `recurringSave` (a per-turn save the consumer ticks) but no per-turn *damage* — the Bearded Devil's infernal wound is automatic HP loss, no save. New **`recurringDamage` condition field** ({dice, damageType, trigger}, the no-save analogue of `recurringSave`) + **`engine.plan.tickRecurringDamage`** (its sibling: rolls the per-tick dice and runs the same mitigation/fatal-intercept/concentration-on-damage pipeline as a recurring spell tick, sourced to the condition's `sourceCharacterId`; consumer-orchestrated). Content: a new `infernal-wound` condition (`recurringDamage {1d10 necrotic}` + `autoExpiry {10 rounds, bearer-keyed}` = closes after 1 minute), applied by the Infernal Glaive's onHit CON-12 save rider. RAW the loss is untyped HP loss → modeled as necrotic (closest typed approximation); the heal-closes + Medicine-stanch arms stay consumer/DM-managed (no heal→remove-condition hook). New 4-test slice-825 (wound applies on a failed save sourced by the devil; the tick drains 1d10 necrotic + lowers HP; ticking a wound-less creature throws). The new condition bumped the doc-cited count (164→165 / 150 rider). `tsc` clean; exports/coverage/doc-counts green; fast suite green (607 files, 4627 passed).
