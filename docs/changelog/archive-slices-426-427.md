**Engine (slice 427): fix species walk speed not reaching created characters**

Fixes the gap slice 426 surfaced: a character's effective walk speed came from `character.speedFeet`, which defaulted to 30 and was never derived from the species, so a Goliath (SRD 35) built via the content-free `createPC` reported walk 30. Made `character.speedFeet` an **optional override** (no default): when set (transformations, summons, a consumer pinning a value) it still wins; when absent, `baseSpeedForMode('walk')` now derives from the species' / statblock's walk speed exactly like the non-walk modes already did, with a 30 ft floor. A created PC now reports its species walk speed; a wild-shaped character still uses the form's speed (set explicitly) and reverts correctly (the snapshot's `speedFeet` is also optional now).

Blast radius was near-zero in practice: every existing fixture uses a 30 ft species (Human) or sets `speedFeet` explicitly, so all speed / golden / replay tests stay green unchanged; one non-walk regression test that asserted the raw default field now asserts the effective speed instead. The species-speed conformance test (426) was updated to build characters without an explicit speed and to assert `createPC` Goliath returns 35 directly. Backward-compatible: old saves that persisted `speedFeet: 30` keep that stored value (it just acts as an explicit override), so no migration and `SCHEMA_VERSION` is unchanged.

Ledger updated: "species walk speed reaches a created character" moves 🔴 to 🟢.

Uncle Bob audit (engine slice): **Names** `DEFAULT_WALK_SPEED` names the former magic literal; `baseSpeedForMode` is unchanged in intent. **DRY** the walk path now shares the species / statblock fallback chain with the non-walk modes instead of special-casing a stored field. **SRP** the schema declares the optional override; the derivation owns the fallback; transformations just copy the value. **Magic numbers** the 30 ft floor is a named constant with a RAW note. **at-threading** n/a (derivation + schema). **Mechanical outcomes asserted** a created PC derives its species walk speed (Goliath 35, others 30); an explicit `speedFeet` override still wins; `createPC` Goliath returns 35; the non-walk + Haste + Grappled + Fast-Movement cases stay unchanged. **Tests** species-speed conformance updated to the species-derived path + a createPC assertion; one non-walk regression assertion retargeted to the effective speed. `tsc --noEmit` clean; full suite green (344 files / 2321 passing). **Test (slice 426): ground-truth species speed conformance, and a surfaced creation gap**

Sixth 🟡→🟢 ledger upgrade. srd-drift verifies monster walk speeds but not species, so species base speed was unverified (and it varies: Goliath 35, the rest 30). New [tests/audit/srd-species-speed-conformance.test.ts](../../tests/audit/srd-species-speed-conformance.test.ts) parses each species' Speed from `character-origins.md` (`**Speed:** 35 feet`) and asserts the pack's species walk speed matches, then confirms the walk-speed derivation returns that base unmodified for a vanilla character. A sanity check requires the one non-30 value (Goliath 35) to be present so a parse that defaulted everything to 30 can't pass. All 9 species verified.

**Surfaced a real gap (tracked, fixed in slice 427):** a character's effective walk speed comes from `character.speedFeet`, but the content-free `createPC` convenience defaults it to 30 rather than deriving it from the species, so a **Goliath built via createPC reports walk 30, not 35.** The species *data* is correct (verified 🟢 above); what's missing is a content-aware creation path that applies it (the consumer must currently set `speedFeet`). Fixing it touches creation/derivation semantics with broad blast radius, so it's deliberately not bundled with this conformance test; tracked as a 🔴 row in the [coverage ledger](../srd-coverage-ledger.md). This is the arc paying for itself a second time (after slice 422's missing firearms): ground-truth comparison found a player-visible wrong number that author-asserted tests missed.

Ledger updated: species base walk speed is now 🟢; the ModifySpeed math + the species→speedFeet creation gap stay 🟡/🔴. Skips when the SRD clone is absent.
