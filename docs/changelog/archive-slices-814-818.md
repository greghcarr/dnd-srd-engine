**Feat (slice 818): Priest Divine Aid (3/Day) — shared per-day pool + cast-time override**
Advances the [L7 audit](l7-completion-audit.md) `npc-caster-bonus-action-groups` quirk (its hardest item). The Priest's RAW Bonus Action *Divine Aid (3/Day)* casts one of Bless / Dispel Magic / Healing Word / Lesser Restoration — 3 uses **total**, all as a Bonus Action — which the per-spell slice-794 model couldn't express. Two additive `GrantSpell` fields: **`perDayPoolId`** shares one N/Day budget across grants tagged with the same id (the cast path sums each member's `perDayCastsUsed` counter vs `usesPerLongRest`; each cast still increments its own spell's counter so `PerDayCastUsed.spellId` stays accurate; long rest clears them). It needs **no resource seeding** — chosen over a `freeCastResourceId` pool because the Priest is the first monster with a resource and no consumer seeds monster resources (the per-day counter is base state). **`castAsBonusAction`** forces `castingTimeKind = 'bonusAction'` for the matched free-cast grant, so Bless + Dispel Magic (Action spells) cost the Bonus Action through Divine Aid; scoped to the grant, so a normal slot cast is unaffected. Content: the Priest gains the four pooled grants. New 4-test slice-818 (the shared-budget proof: three different spells block a fourth never-cast pool spell; long-rest refresh; Action→Bonus-Action override); slice-795's per-spell Spirit Guardians stays green. `tsc` clean; coverage/exports snapshots unchanged; fast suite green (600 files, 4591 passed).

**Feat (slice 817): Misty Step per-day enabler — slot-less NPC casters**
Advances the [L7 audit](l7-completion-audit.md) `npc-caster-bonus-action-groups` quirk. Misty Step has a *dedicated* planner (`planMistyStep` — it needs a destination + does the teleport, so it's off the generic `castSpell` path); that planner always expended a spell *slot* and recognized only known/prepared spells, so a slot-less Mage/Archmage (whose statblock prints "Misty Step (3/Day)") couldn't cast it. Added a `useFreeCast` branch mirroring castSpell's slice-794 machinery: a granted Misty Step (effect-stack `GrantSpell`) satisfies the "knows the spell" check, and a `perLongRest` ("N/Day") grant meters `perDayCastsUsed` + emits `PerDayCastUsed` instead of `SpellSlotConsumed`. The effect stack is built lazily so the player slot path is byte-identical (`MistyStepIntent.useFreeCast?` flows through the existing wiring; no API change). Content: `misty-step` granted 3/Day to the Mage + Archmage (RAW `monsters-A-Z.md`). New 4-test slice-817 (per-day cast = teleport + PerDayCastUsed no slot + metered; 3/Day budget enforced; granted-spell recognition; no-grant rejection); the existing `plan-misty-step` sorcerer slot test stays green. `tsc` clean; coverage/exports snapshots unchanged; fast suite green (599 files, 4587 passed).
Detail: [slice-817.md](slice-817.md).

**Fix (slice 816): Spiritual Weapon's immediate attack no longer costs the Action**
Closes the [L7 audit](l7-completion-audit.md) `spiritual-weapon-immediate-attack-action-cost` divergence (surfaced by slice 815). `cast-spell.ts` charged a Bonus-Action spell *both* a Bonus Action and an Action when cast at a target — slice 603's model for a spell whose attack is a *separate* Magic action (Produce Flame "take a Magic action to hurl fire"). It was keyed on a `duration !== instantaneous` heuristic that also caught **Spiritual Weapon**, whose attack RAW is made *immediately* as part of the Bonus-Action cast (no separate Action) — so every Spiritual Weapon caster (cleric, player, monster) wrongly lost their Action. Replaced the heuristic with an explicit per-attack `requiresMagicAction` flag on `SpellAttackMechanicSchema` — authored `true` on Produce Flame + Flame Blade (genuine separate Magic action), unset on Spiritual Weapon. Now the immediate-on-cast attack costs only the Bonus Action; the separate-Magic-action hurl still costs both (slice-603 behavior preserved). New 4-test slice-816 (player-cleric Spiritual Weapon = BA only; druid Flame Blade = BA + Action; flag authored right; a durable invariant guarding the heuristic→flag switch); slice-815 #4 flipped to the fixed behavior. `tsc` clean; coverage/exports snapshots unchanged; fast suite green (598 files, 4583 passed).
Detail: [slice-816.md](slice-816.md).

Added *Spiritual Weapon* 2/Day to the Cultist Fanatic as `GrantSpell{perLongRest:2}`: an intrinsic Bonus-Action spell on the generic `castSpell` path, so its BA economy + per-day metering fall out of the slice-794 primitive (no engine change). Triaged the rest as engine seams: Misty Step 3/Day (Mage/Archmage) routes through the dedicated slot-consuming `planMistyStep` — needs a per-day branch (correcting the slice-814 note that it rode `castSpell`); Divine Aid 3/Day (Priest) is a shared pool + Action→BA cast-time override; Protective Magic 3/Day is a Counterspell/Shield reaction; Dryad Tree Stride is a movement ability, not a spell. Surfaced a pre-existing divergence (tracked `spiritual-weapon-immediate-attack-action-cost`): casting Spiritual Weapon at a target also spends the Action via `consumesImplicitMagicAction` (built for Produce Flame's separate hurl), though RAW the immediate attack is part of the Bonus-Action cast — affects every Spiritual Weapon caster, so an engine fix not content. New 4-test slice-815 (metering + BA-only summon + characterized implicit-action). `tsc` clean; fast suite green.
