dnd-srd-engine web demo

A randomized D&D 5.5e battle, generated by the same simulator that powers scripts/combat-fuzz.ts. Pick a seed, hit Run, then scrub the cursor in the Fuzz Replay panel to step through every committed event. The map and event inspector follow the cursor.

Booting...

Use the transport in the Fuzz Replay panel to scrub one event at a time, or hit ▶ for auto-advance. Use Verify replay in the inspector at any cursor to confirm replay(events).state matches the live state for that slice. The URL hash captures the full config (seed, mode, vs, level, rest) plus the cursor (step) so any moment in any battle is sharable.
