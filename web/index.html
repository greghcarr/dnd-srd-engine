dnd-srd-engine web demo

A randomized D&D 5.5e battle, generated by the same simulator that powers scripts/combat-fuzz.ts. Pick a seed, hit Run new battle, then scrub the transport in the Random Battle panel to step through every committed event. The Event Log follows the same step.

Booting...

Use the transport in the Random Battle panel to step one event at a time, or hit ▶ for auto-advance. Open Developer tools in the Event Log to verify replay(events).state matches the live state for any slice, or to export / import a campaign as JSON. The URL hash captures the full config (seed, mode, vs, level, rest) plus the current step so any moment in any battle is sharable.
